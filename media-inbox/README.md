# Media inbox

Upload audio and images here on GitHub: **Add file → Upload files**, then **Commit changes**.
The Media workflow converts them, moves them into `public/media/`, and redeploys. About 10
minutes later they're in the app's pickers, and an Excel sheet can name them.

- **Audio:** mp3, wav, m4a, aac, ogg or flac, up to 25 MB per file on the GitHub website.
- **Images:** png, jpg, webp or svg.
- **Names are how files are found, so make them unique to the test:** `b22t1-p1.mp3` is
  Book 22 Test 1 Part 1, `b22t1-w1.png` its Writing Task 1 chart. Uploading a file with a name
  that's already used **replaces** that file everywhere it's used.
- **Cambridge book audio is renamed for you:** `Cambridge IELTS 10.1.2 [@channel].mp3` (or
  `IELTS 10 Test 1 Part 2.mp3`) becomes `b10t1-p2.mp3`, Book 10 Test 1 Part 2. Use that name in
  the Excel Listening sheet. Tags in [brackets] or (brackets) are dropped from other names.
