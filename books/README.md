# Books

Upload book PDFs here on GitHub (**Add file → Upload files**, then **Commit changes**) so Claude
can read them and turn their tests into drafts. Nothing here is deployed: the site never serves
these files, and uploading one doesn't start a deploy. The repository is private; keep it that way.

The GitHub website takes files up to 25 MB. A bigger PDF can be split, for example one file per
test.
